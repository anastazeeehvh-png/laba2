# Система учёта студентов

## Назначение
Информационная система для учёта студентов учебного заведения: ведение списка студентов, групп и успеваемости.

## Требования к окружению
- Python 3.10 или выше
- Git 2.30 или выше
- ОС: Windows 10/11, Linux, macOS

## Инструкция по запуску (предварительная)
1. Клонировать репозиторий: `git clone <URL>`
2. Перейти в каталог проекта: `cd student-accounting`
3. Запустить программу: `python src/main.py`

## Структура проекта
- `src/` — исходный код
- `docs/` — документация (техническое задание)
- `tests/` — тесты
