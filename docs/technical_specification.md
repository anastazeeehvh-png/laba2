# Техническое задание на разработку системы «Учёт студентов»
(по ГОСТ 19.201-78)

## 1 Введение
### 1.1 Наименование программы
«Учёт студентов».
### 1.2 Область применения
Программа предназначена для учёта студентов учебного заведения: хранение личных данных, распределение по группам, учёт успеваемости.

## 2 Основания для разработки
Разработка ведётся в рамках учебной дисциплины «Инструментальные средства разработки программного обеспечения».

## 3 Назначение разработки
Добавление, редактирование, удаление и поиск студентов; просмотр списка студентов по группам.

## 4 Требования к программе
- хранение данных студента: ФИО, номер группы, дата рождения, средний балл;
- добавление, изменение и удаление записей;
- поиск по ФИО и по группе;
- сохранение данных в файл.

## 5 Требования к программной документации
Техническое задание, руководство пользователя, README.md.

## 6 Стадии и этапы разработки
Техническое задание, разработка программы, испытания.

## 7 Порядок контроля и приёмки
Проверка выполнения функциональных требований.
