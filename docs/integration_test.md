## Роли тестов при риск-ориентированной интеграции

- `test_processing.py`, `test_api.py` — этап 1. Модуль обработки проверяется отдельно, тест играет роль **драйвера**: заменяет модули ввода и отчёта и обращается к API напрямую.
- `test_input.py` — этап 2. Драйвер заменён настоящим модулем ввода.
- `test_integration.py` — этап 3. Подключён модуль отчёта, проверяется вся цепочка.
